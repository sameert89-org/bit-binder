## Problem Statement
You are given a 2D integer array grid of size m x n.

You must select exactly one integer from each row of the grid.

Return an integer denoting the minimum possible bitwise OR of the selected integers from each row.

Example 1:

Input: grid = [[1,5],[2,4]]

Output: 3

Explanation:

Choose 1 from the first row and 2 from the second row.
The bitwise OR of 1 | 2 = 3, which is the minimum possible.
Example 2:

Input: grid = [[3,5],[6,4]]

Output: 5

Explanation:

Choose 5 from the first row and 4 from the second row.
The bitwise OR of 5 | 4 = 5, which is the minimum possible.
Example 3:

Input: grid = [[7,9,8]]

Output: 7

Explanation:

Choosing 7 gives the minimum bitwise OR.
 

Constraints:

1 <= m == grid.length <= 105
1 <= n == grid[i].length <= 105
m * n <= 105
1 <= grid[i][j] <= 105

## Discussion
I got stuck here really bad, it took my whole hour of trying to figure out, its because I had not done such greedy pattern on bits before, basically for any such problem requiring you to find optimal solution often involves *optimizing* for MSB, because any other after MSB will not matter.

I checked out the hint 1 after the contest and it mentioned solving bit by bit from MSB, I had already figured that out, since XOR grows when there is less overlap between two numbers, so if we could maximize the overlap we could somehow minimize the XOR but I just could not figure it out.

After seeing the hint, I came up with a crude solution, where I go from the MSB and try to make each bit zero, I loop over every row for each (because it can be max 32 * m * n, well within time bounds) and I find out whether its possible to make zero that row, I was doing this using a bitmask with that bit set and and-ing the mask with the number if I get a 0 that means that number exists which can make that bit zero for that row. If all rows are capable of giving a zero means that bit has to be zero in the result so I move on, if not I just or the result with the mask making that bit set.

But this still did not clear things, since I can only pick 1 digit from each row, how do I disqualify the digits? a digit which can give zero on kth bit must not give a 1 at k + 1th bit if it has been established that that bit (is more significant) and can be made zero in the previous run. I came up with a filter to mark the numbers which couldn't give me zero in that run as -1 but that fell on its head because if it was found that it was impossible to make kth bit zero then its unfair to disqualify numbers in that position since they could be either zero or one.

This was the reason I could not solve it.

The solution for this is to use the result itself as the filter, the numbers which qualify should OR with the result and not increase its value from that point onwards, well only for the bits we have processed till now (because obviously we cannot be certain for next bits and result may grow more)


```python
class Solution:
    def minimumOR(self, grid: List[List[int]]) -> int:
        R = len(grid)
        C = len(grid[0])
        result = 0
        def can_this_bit_be_zero(bit_index: int):
            if bit_index < 0 or bit_index > 31:
                raise ValueError(f"bit_index out of range, bit_index: {bit_index}")
                
            mask = 1 << bit_index
            partial_result_mask = result >> bit_index
            
            for row in range(R):
                can_this_row_make_it_zero = False
                for col in range(C):
                    if mask & grid[row][col] == 0 and partial_result_mask | (grid[row][col] >> bit_index) == partial_result_mask: # this second condition means that the number does not increase the value of the result
                        can_this_row_make_it_zero = True
                        break
                if not can_this_row_make_it_zero:
                    return False # all rows must be capable of making a zero

            return True
        
        for bit in range(31, -1, -1):
            if not can_this_bit_be_zero(bit):
                # print(bit)
                result |= (1 << bit)

        return result
```
