| **n**                 | **Possible complexities**      |
| --------------------- | ------------------------------ |
| $n \leq 10$           | $O(n!), O(n^7), O(n^6)$        |
| $n \leq 20$           | $O(2^n \cdot n), O(n^5)$       |
| $n \leq 80$           | $O(n^4)$                       |
| $n \leq 400$          | $O(n^3)$                       |
| $n \leq 7500$         | $O(n^2)$                       |
| $n \leq 7 \cdot 10^4$ | $O(n\sqrt{n})$                 |
| $n \leq 5 \cdot 10^5$ | $O(n \log n)$                  |
| $n \leq 5 \cdot 10^6$ | $O(n)$                         |
| $n \leq 10^{18}$      | $O(\log^2 n), O(\log n), O(1)$ |
