2. [[Adapter]] : (Very High) - Normalizing third-party SDKs and AI model responses into a single internal interface.
3. [[Decorator]] : (High) - Adding cross-cutting concerns like Auth, Logging, and Middleware via modern language annotations.

5. [[Composite]] : (Medium) - Building hierarchical UI component trees in frameworks like React, Vue, and Flutter.
6. [[Bridge]] : (Low) - Decoupling platform-independent abstractions from OS-specific implementations in cross-platform drivers.
7. [[Flyweight]] : (Very Low) - Minimizing memory footprint by sharing granular state in high-performance text editors or game engines.
