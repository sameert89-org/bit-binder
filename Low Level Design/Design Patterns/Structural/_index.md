Ranking from most used to least used:

1. [[Facade]] - **Universal:** Provides simplified entry points to complex microservices and backend API controllers.
2. [[Adapter]] - **Very high:** Normalizes third-party SDKs and AI model responses into a single internal interface.
3. [[Decorator]] - **High:** Adds cross-cutting concerns such as authentication, logging, and middleware through modern language annotations.
4. [[Proxy]] - **High:** Controls resource access through lazy loading in ORMs or traffic routing in API gateways.
5. [[Composite]] - **Medium:** Builds hierarchical UI component trees in frameworks such as React, Vue, and Flutter.
6. [[Bridge]] - **Low:** Decouples platform-independent abstractions from OS-specific implementations in cross-platform drivers.
7. [[Flyweight]] - **Very low:** Minimizes memory usage by sharing granular state in high-performance text editors or game engines.
