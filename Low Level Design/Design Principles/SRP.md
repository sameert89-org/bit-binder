> **A class should have one, and only one, reason to change.**
>
> "A class should have only one stakeholder."
>
> "A module should do one job."

The change should be requested by only one stakeholder.

> [!NOTE] The God Class
> A class that tries to do everything. Things that try to do everything do nothing well.

Focus on **cohesion**, not fragmentation. Group logic that changes together or belongs to the same business concern.
